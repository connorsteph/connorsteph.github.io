### connorsteph.github.io

Static site, no build step. Hand-written HTML/CSS; shared nav in `js/nav.js` + `js/components.js`; styles in `style.css`.

To run locally: `python3 -m http.server 8080` then open http://localhost:8080

Notes live in `posts/` (see `posts/posts.json`); project write-ups in `projects/`.
Paper and ink textures in `static/textures/` are derived from Made by Gray scans (licensed).
