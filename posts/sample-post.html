The Gaussian integral is a fundamental result in mathematics:

$$\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}$$

Euler's identity beautifully connects five fundamental mathematical constants:

$$e^{i\pi} + 1 = 0$$

Code Examples

You can also include code snippets in your posts:


import numpy as np
import matplotlib.pyplot as plt

def gaussian_function(x, mu=0, sigma=1):
    """Compute the Gaussian function at x."""
    return (1 / (sigma * np.sqrt(2 * np.pi))) * np.exp(-0.5 * ((x - mu) / sigma)**2)

# Generate sample data
x = np.linspace(-5, 5, 1000)
y = gaussian_function(x)

# Plot the result
plt.figure(figsize=(8, 6))
plt.plot(x, y, 'b-', linewidth=2, label='Gaussian')
plt.xlabel('x')
plt.ylabel('f(x)')
plt.title('Gaussian Function')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
